# Roast the Smart Fridge

Entry for [Roast the Smart Fridge: One Line, Best Laugh Wins](https://make.fun/bounty/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9) on make.fun.

`main.ts` writes a single roast line (at most 160 characters) to `/output/entry.txt`:

> My fridge's ice maker sounds like cutlery in a washing machine and makes one cube an hour, like it's rationing winter.

Run it with `node main.ts` (Node 22.18+). The output directory comes from `MAKEFUN_OUTPUT_DIR` and defaults to `/output`.
